سامانه مدیریت عقرب — نسخه اولیه بک‌اند

این بسته یک اسکلت اجرایی برای ربات مدیریتی + API + دیتابیس SQLite است.
توجه: این بسته به‌تنهایی هنوز به HTML فعلی بازی متصل نشده و تأیید پرداخت Pexn نیز بدون تطبیق قالب callback واقعی سایت کامل نیست.

امکانات فعلی:
- دستور /admin برای پنل ادمین در تلگرام
- نمایش کاربران ثبت‌شده و آمار
- /user ID
- /addpoints ID AMOUNT دلیل
- /removepoints ID AMOUNT دلیل
- /block ID و /unblock ID
- /tier ID free|vip|cip
- API برای دریافت وضعیت کاربر و اشتراک با اعتبارسنجی Telegram WebApp initData
- endpoint نمونه برای پرداخت تأییدشده: POST /api/payments/confirmed

راه‌اندازی:
1) Python 3.11+ نصب باشد.
2) در پوشه پروژه اجرا کنید:
   pip install -r requirements.txt
3) فایل .env.example را به .env تغییر نام دهید و مقدارهای BOT_TOKEN و ADMIN_IDS را تنظیم کنید.
   ADMIN_IDS شناسه عددی تلگرام ادمین است. شناسه را از یک ربات نمایش‌دهنده User ID بگیرید.
4) متغیرهای محیطی را در محیط هاست وارد کنید. این کد فایل .env را خودکار نمی‌خواند؛ برای اجرای محلی می‌توانید متغیرها را در سیستم تعریف کنید یا python-dotenv اضافه کنید.
5) اجرا:
   python main.py
6) در ربات تلگرام دستور /admin را بزنید.

امنیت و محدودیت‌ها:
- هرگز BOT_TOKEN یا API_SECRET را در HTML عمومی قرار ندهید.
- قبل از استفاده واقعی، API را روی HTTPS اجرا کنید.
- کاربران زمانی در دیتابیس ظاهر می‌شوند که مینی‌اپ به endpoint های API متصل شده باشد.
- درگاه پرداخت باید callback معتبر server-to-server بفرستد؛ فقط برگشت کاربر به ربات کافی نیست.
- قالب webhook این پروژه نمونه است و باید مطابق مستندات واقعی Pexn تنظیم شود.
- برای اینکه تغییر امتیاز/مسدودسازی واقعاً روی بازی اثر کند، منطق بازی باید به API متصل شود و سرور مرجع اصلی موجودی باشد.
